# Gestion des biens

## Fonctionnalités

- créer un bien ;
- définir son type ;
- associer un propriétaire ;
- ajouter les caractéristiques ;
- ajouter des photos ;
- ajouter des documents ;
- définir le statut ;
- consulter l'historique des contrats.

## Statuts

- disponible ;
- occupé ;
- maintenance ;
- inactif.

Un bien ne peut pas avoir deux contrats actifs qui se chevauchent.

Cette règle doit être contrôlée côté application et base de données lorsque possible.
