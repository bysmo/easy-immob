# UX et UI

L'interface doit être professionnelle et responsive.

## Dashboard

Le dashboard doit donner immédiatement une vision de :
- l'activité ;
- les revenus ;
- les impayés ;
- les échéances ;
- les contrats.

## Principes

- navigation simple ;
- recherche globale ;
- filtres ;
- tableaux paginés ;
- actions rapides ;
- confirmations pour actions sensibles ;
- messages de succès ;
- messages d'erreur compréhensibles.

## Mobile

L'application doit être parfaitement utilisable sur :
- desktop ;
- tablette ;
- mobile.

Les tableaux complexes doivent devenir des cartes sur mobile.
