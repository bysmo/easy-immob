# Paiements et finances

## Dashboard financier

Afficher :
- loyers attendus ;
- loyers encaissés ;
- loyers en retard ;
- montant total des impayés ;
- revenus par propriétaire ;
- revenus par bien ;
- paiements par période.

## Paiement

Chaque paiement doit avoir :
- montant ;
- date ;
- méthode ;
- référence ;
- justificatif éventuel ;
- utilisateur ayant enregistré le paiement.

Les suppressions de paiements doivent être strictement contrôlées et auditées.
