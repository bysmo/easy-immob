# Gestion des loyers

## Échéances

Chaque contrat actif génère des échéances mensuelles.

Chaque échéance contient :
- période ;
- date d'échéance ;
- montant du loyer ;
- charges ;
- montant total ;
- montant payé ;
- solde.

## Paiements

Un paiement peut être :
- total ;
- partiel.

Méthodes possibles :
- espèces ;
- virement ;
- mobile money ;
- carte ;
- chèque ;
- autre.

## Quittance

Après paiement total, une quittance peut être générée automatiquement.

## Règle

Un paiement doit être enregistré dans une transaction DB.
