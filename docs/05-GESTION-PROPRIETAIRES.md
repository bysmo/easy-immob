# Gestion des propriétaires

## Fonctionnalités

- créer un propriétaire ;
- modifier un propriétaire ;
- désactiver un propriétaire ;
- rechercher ;
- filtrer ;
- consulter ses biens ;
- consulter ses revenus ;
- consulter ses contrats ;
- consulter les impayés liés à ses biens ;
- consulter ses documents.

## Règles

Un propriétaire peut posséder plusieurs biens.

Un propriétaire désactivé ne doit pas être supprimé physiquement si des données historiques existent.

Utiliser le soft delete lorsque nécessaire.
