# Architecture fonctionnelle

## Dashboard

Le dashboard doit afficher :
- nombre total de biens ;
- biens occupés ;
- biens vacants ;
- contrats actifs ;
- loyers attendus ;
- loyers encaissés ;
- impayés ;
- montants des impayés ;
- contrats expirant bientôt ;
- loyers à échéance prochaine.
