# Gestion des cautions

## Cycle

1. caution prévue ;
2. caution reçue ;
3. caution détenue ;
4. caution partiellement retenue ;
5. caution totalement restituée.

## Informations

- montant prévu ;
- montant reçu ;
- date de réception ;
- retenues ;
- motif des retenues ;
- montant restitué ;
- date de restitution.

Toute retenue doit être justifiée.
