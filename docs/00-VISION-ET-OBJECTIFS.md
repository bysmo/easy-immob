# Vision et objectifs

## Objectif

Créer une plateforme professionnelle de gestion immobilière destinée aux agences immobilières.

L'application doit centraliser toutes les opérations de gestion locative.

## Objectifs principaux

- centraliser les propriétaires ;
- centraliser les biens ;
- gérer les locataires ;
- automatiser les contrats ;
- automatiser la génération des loyers ;
- suivre les paiements ;
- gérer les cautions ;
- détecter les impayés ;
- automatiser les relances ;
- notifier les parties prenantes ;
- produire des documents professionnels ;
- produire des rapports fiables.

## Principes

L'application doit être :
- sécurisée ;
- simple à utiliser ;
- rapide ;
- responsive ;
- extensible ;
- auditable ;
- compatible avec une future application mobile.

## Utilisateurs

- administrateur ;
- gestionnaire immobilier ;
- comptable ;
- agent immobilier ;
- propriétaire ;
- locataire.

Les propriétaires et locataires pourront ultérieurement disposer d'un portail dédié.
