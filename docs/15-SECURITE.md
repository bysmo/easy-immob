# Sécurité

## Authentification

Utiliser Laravel Fortify ou Jetstream.

## Autorisation

Utiliser :
- Policies ;
- Gates ;
- permissions granulaires.

## Données sensibles

Les pièces d'identité et documents doivent être privés.

## Audit

Journaliser :
- création ;
- modification ;
- suppression ;
- paiement ;
- annulation ;
- téléchargement de document ;
- changement de permission.

## Protection

Prévoir :
- CSRF ;
- XSS ;
- SQL Injection ;
- rate limiting ;
- validation ;
- contrôle des uploads ;
- contrôle des MIME types ;
- contrôle de taille ;
- noms de fichiers générés aléatoirement.
