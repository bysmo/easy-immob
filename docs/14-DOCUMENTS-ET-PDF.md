# Documents et PDF

## Documents générés

- contrat ;
- quittance ;
- reçu ;
- état des paiements ;
- relevé propriétaire ;
- état des impayés.

## Sécurité

Les documents doivent être stockés dans un disque privé.

L'accès doit être contrôlé par Policy.

Utiliser des URLs temporaires lorsque nécessaire.

## PDF

La génération doit être centralisée dans des services dédiés.

Exemples :
- ContractPdfService ;
- ReceiptPdfService ;
- RentStatementPdfService.
